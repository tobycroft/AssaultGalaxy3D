🎬Scene Building
Create a Complete 2D Game Scene
Create a new 2D game scene in Cocos Creator with:
1. Canvas node with solid color background (#1a1a2e)
2. Player sprite at position (0, -200) named "Player"
3. Ground platform at position (0, -400)
4. UI layer: Score label (top-right), Health bar (top-left), Pause button
5. Camera set to follow the player
Build a Main Menu Scene
Create a main menu scene with:
1. Background image
2. Title "GAME TITLE" centered at top (font-size: 48, bold)
3. Three buttons: "Start Game", "Settings", "Exit"
4. Version text at bottom-right (small, gray)
5. Smooth fade-in animation on scene load (0.5s)
🖼️UI Building
Create an Inventory Panel
Build an inventory UI panel:
1. Semi-transparent dark background, rounded corners
2. Grid layout with 4x5 inventory slots (64x64 each)
3. Drag-and-drop support between slots
4. "Inventory" title + close button
5. Item count badge on each slot
6. Scale-up opening animation (0.3s)
Game HUD / Heads-Up Display
Create a complete game HUD:
1. Health bar (red fill, white border) + numeric display (top-left)
2. Mana/Energy bar (blue fill) below health
3. Score display (top-right)
4. Level/Stage indicator
5. Ability cooldown icons (3-4 buttons, bottom-center)
6. Virtual joystick (bottom-left, if mobile)
✨Animation & FX
Character Idle Animation
Create a character idle animation:
1. Add Animation component to character node
2. Create "idle" animation clip (looping)
3. Breathing scale: 0.95 to 1.05, 2s cycle, ease in-out
4. Vertical bob: up 2px, 2s cycle
5. Blink effect on "eyes" child node (every 3-5s)
6. Set animation to play on load
Particle Effects Collection
Create particle effect presets:
1. Explosion: orange/red burst, expanding outward, 0.5s lifetime
2. Coin collect: yellow particles burst upward in arc
3. Level up: golden particles spiral upward
4. Damage flash: character flashes red (0.1s)
5. Teleport: blue particles converge inward then outward
6. Trail effect: particles follow moving object
🔧Components
2D Physics Setup
Set up 2D physics for a platformer:
1. Enable 2D physics in project settings
2. Add RigidBody2D to player (Dynamic, fixed rotation)
3. Add BoxCollider2D to player (match sprite size)
4. Add RigidBody2D (Static) + BoxCollider2D to ground/platforms
5. Set gravity to (0, -980)
6. Configure collision matrix for player-vs-enemy and player-vs-collectible
Interactive Button with States
Create an interactive button with full state management:
1. Add Button component to the node
2. Normal state (default sprite)
3. Hover state (brighter sprite, scale 1.05)
4. Pressed state (darker sprite, scale 0.95)
5. Disabled state (grayed out)
6. Add click sound effect
7. Transition component for smooth state switching
8. Wire onClick event to the appropriate action
📦Prefabs
Create a Character Prefab
Create a reusable character prefab:
1. Root "Character" with: Sprite, RigidBody2D, BoxCollider2D, Animation
2. Child "HealthBar" (floating health bar)
3. Child "WeaponSlot" (empty mount point)
4. Child "Effects" (hit sparks etc.)
5. Expose properties: moveSpeed, jumpForce, maxHealth
6. Add Character script with basic movement logic
Projectile / Bullet Prefab
Create a projectile prefab with:
1. Sprite component for visual
2. RigidBody2D (Kinematic) for movement
3. Collider that triggers on contact
4. Auto-destroy after 3s or on collision
5. Trail particle effect
6. Configurable: speed, damage, direction
7. Impact effect prefab reference (spawned on hit)
🐛Debug
Full Scene Audit
Perform a full audit of the current scene:
1. List all nodes with hierarchy depth
2. Count nodes per type (Sprite, Button, Label, etc.)
3. Identify nodes without any component
4. Find nodes with missing sprite frames or materials
5. Check for textures larger than 2048px
6. Report nodes with high draw calls
7. List all active scripts and their update frequency
8. Identify unused assets
9. Report total vertex count and draw calls
10. Suggest optimization opportunities
Fix Common Scene Issues
Scan and fix common issues in the current scene:
1. Find nodes at (0,0,0) that should be elsewhere
2. Identify overlapping UI elements
3. Find nodes with scale (0,0,0) or very large scale
4. Components with missing references (null sprite frames)
5. Verify all button onClick targets are valid
6. Animation clips referencing deleted nodes
7. Prefab instances with broken prefab links
🗂️Assets
Organize Project Assets
Help me organize my project assets:
1. List all assets grouped by type
2. Suggest folder structure: textures/, audio/, prefabs/, animations/, scripts/, scenes/, materials/, fonts/
3. Move mislocated assets to appropriate folders
4. Update all references after moving
5. Remove duplicate or unused assets
⚡Workflows
Batch Rename Nodes
Batch rename nodes in the current scene:
1. Find all nodes matching a pattern [specify]
2. Rename with convention like "Enemy_01", "Enemy_02"
3. Update script references to renamed nodes
4. Report changes made
Batch Add/Modify Components
Batch operation on multiple nodes:
1. Find all nodes of type [specify]
2. Add component [specify] to each
3. Set property [name] to [value] on all
4. Verify the changes
5. Report any failed or skipped nodes
